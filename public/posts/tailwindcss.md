# TailwindCSS 介绍

> Tailwind CSS 的工作原理是扫描所有 HTML 文件、JavaScript 组件以及任何 模板中的 CSS 类（class）名，然后生成相应的样式代码并写入 到一个静态 CSS 文件中

github 地址:https://github.com/tailwindlabs/tailwindcss

TailwindCSS 官网:https://tailwindcss.com/
